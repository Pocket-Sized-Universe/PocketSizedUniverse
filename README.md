# Pocket Sized Universe
#### Mod syncing that ***you*** control!
##### Syncs your Penumbra/Glamourer and other glam plugins with your friends using peer-to-peer tech


### What is it?
Pocket Sized Universe (PSU) is a Dalamud plugin for FFXIV that syncs your mods to your friends using robust peer-to-peer protocols. It uses [IPFS](https://ipfs.tech/) (The Interplanetary File System) in the background to allow you and your friends to see each other the way you want to be seen!

### Main Features
- Private two way mod syncs via star codes
- Group syncing via Galaxies
- Private chat room system that's separate from FFXIV's in-game chat
- Global Sync: an optional way to see and be seen by everyone who's currently using PSU!
- Fully decentralized (No cease and desist risk here!)

### How do I get started?
1. Add the repo link above to the Experimental tab in /xlsettings
2. Install "Pocket Sized Universe" from /xlplugins
3. Follow the in-game setup wizard
4. Share your pairing codes with your friends!
5. Join our [Discord](https://discord.gg/7E8cv6R8Ze) to be part of an awesome community and get notified of updates (Optional)
6. Have fun!
